**LogSleuth 0.4.2 — a readability and usability pass over the live stream.**

`versionName` 0.4.2, `versionCode` 13.

Requires Android 8.0 (API 26)+.

## Improved

- **Log colors are readable in light theme.** Level colors used to be one bright set tuned for dark backgrounds — green and orange text was hard to read on white. Both themes now have their own palette, every color checked for contrast, and the level badge letter automatically picks black or white so it stays legible too. (#185, closes #184)
- **Entry details sit beside the list on wide screens.** On landscape phones, tablets and foldables (including split-screen), tapping a line opens a docked panel on the right instead of a sheet covering the stream — long stacks scroll inside the panel while the copy and filter buttons stay in view. Phones keep the bottom sheet. (#185, closes #184)
- **Smoother scrolling under heavy log traffic.** Timestamp formatting is now cached instead of redone on every redraw, and the list recycles rows more efficiently, so fast streams stutter less. (#185, closes #184)
- **Log rows work with TalkBack.** Copying a line no longer requires a long press — it is offered as an accessibility action, the tap is announced for what it does (open details, or extend the selection), and the decorative icon no longer reads as a separate item. (#185, closes #184)
- **Tidier log metadata.** The uid and pid/tid columns line up with real spacing instead of space characters, so they stay aligned on every device font. (#185, closes #184)

**LogSleuth 0.4.2 —— 实时日志流的一轮可读性与易用性打磨。**

`versionName` 0.4.2，`versionCode` 13。

需要 Android 8.0（API 26）及以上。

## 改进

- **浅色主题下日志颜色看得清了。** 级别颜色原先只有一套为深色背景调校的亮色，绿色、橙色文字在白底上很难辨认。现在亮暗主题各有一套经过对比度校验的配色，级别徽章的字母也会自动选黑或白，保证清晰可读。(#185, closes #184)
- **宽屏上日志详情停在列表旁边。** 横屏手机、平板和折叠屏（含分屏）上，点一行日志会在右侧打开停靠面板，不再用弹层盖住日志流——长堆栈在面板内滚动，复制和过滤按钮始终可见。手机竖屏仍是底部弹层。(#185, closes #184)
- **大量日志涌入时滚动更顺滑。** 时间戳格式化改为缓存复用，不再每次重绘都重新计算，列表行回收也更高效，高速日志流下的卡顿更少。(#185, closes #184)
- **日志行支持 TalkBack。** 复制一行不再依赖长按——读屏用户可直接使用无障碍动作，点击会播报实际作用（打开详情或扩展选区），装饰性图标也不再被单独朗读。(#185, closes #184)
- **日志元信息排列更整齐。** uid 与 pid/tid 列改用真实间距对齐，不再靠空格字符拼凑，任何设备字体下都能对齐。(#185, closes #184)

**LogSleuth 0.4.4 brings local MCP to Termux, adds remote log capture, and refreshes the viewer from first launch through report export.**

`versionName` 0.4.4, `versionCode` 15.

Requires Android 8.0 (API 26) and newer.

## Added

- **Local MCP in Termux.** Pair an AI client on the same Android device to record logs, cite saved line numbers, bookmark key events, and exchange reports. Install the bridge from this release and follow the [Termux setup guide](https://shiaho777.github.io/LogSleuth/guide/local-mcp.html). (#216, closes #215)
- **Remote device logs.** Read another Android device over classic TCP ADB with the same filters, recording, and crash detection that work on local logs. (#196, closes #195)
- **Automation rules.** Send matching log lines to Tasker or MacroDroid using a broadcast with a per-rule cooldown. (#194, closes #192)
- **Versioned SDK.** Add the SDK as a Maven dependency and open its exported ZIP directly in LogSleuth from Android’s share sheet. (#198, closes #197)

## Improved

- **Start with a report.** Explore a fictional checkout crash or import a log file on first launch without granting device log access. The updated navigation, settings, and crash screens share the same visual design. (#189, #200)
- **Keep your place while reading.** Move between search matches as logs arrive, clear individual filter fields, and jump from bookmarks to nearby lines. Sessions are grouped by source, and entry details switch between the message and raw log. (#204, closes #202)
- **Spring transitions.** Bottom navigation, page tabs, dialogs, and bottom sheets animate continuously as you switch or dismiss them. (#206, #208)
- **An illustrated quick start.** Eight screenshots follow the app from first launch and permissions to filtering, replay, report export, and the crash stack. (#210, #212, #214)

## Fixed

- **Recordings preserve their source and context.** A source change saves the active recording, delayed lines are recovered from history where possible, and any remaining gaps are marked. Guided reports preview and export the session they captured. (#198, #203)
- **Crash histories preserve simultaneous failures.** Interleaved crashes keep their own stacks, repeated crashes share an updating notification, and old context files are cleaned up. (#194, closes #192)
- **Clearer handling of invalid filters and large selections.** Invalid regular expressions show an error. Large copies can be saved as a session, and recording write errors keep the lines already on disk. (#191, closes #190)

**LogSleuth 0.4.4 支持 Termux 本地 MCP 和远程日志采集，并更新了从首次启动到导出报告的界面与流程。**

`versionName` 0.4.4，`versionCode` 15。

需要 Android 8.0（API 26）及以上。

## 新增

- **Termux 本地 MCP。** 在同一台安卓设备上配对 AI 客户端，即可录制日志、引用会话行号、标记关键时刻和传输报告。从本次发布下载桥接包，按[安装指南](https://shiaho777.github.io/LogSleuth/zh/guide/local-mcp.html)完成配对。(#216, closes #215)
- **远程设备日志。** 通过传统 TCP ADB 读取另一台安卓设备的日志，可以使用与本机相同的筛选、录制和崩溃检测。(#196, closes #195)
- **自动化规则。** 将匹配的日志通过广播发送给 Tasker 或 MacroDroid，每条规则可以单独设置冷却时间。(#194, closes #192)
- **带版本号的 SDK。** 可通过 Maven 依赖接入 SDK。它导出的 ZIP 也可以从 Android 分享面板直接用 LogSleuth 打开。(#198, closes #197)

## 改进

- **打开应用就能看报告。** 首次启动即可查看虚构的结账崩溃或导入日志文件，两种方式都无需设备日志权限。导航、设置和崩溃界面也采用了统一设计。(#189, #200)
- **读日志时更容易找回位置。** 日志持续进入时仍可在搜索结果间跳转，也可逐项清除筛选、从书签跳到附近的日志。会话按来源分组，日志详情可切换消息和原始行。(#204, closes #202)
- **弹簧过渡。** 底部导航、页内标签、弹窗和底部面板在切换或关闭时都有连贯动效。(#206, #208)
- **图文上手。** 八张截图依次展示首次启动、权限设置、筛选、回放、报告导出和崩溃堆栈。(#210, #212, #214)

## 修复

- **录制保留来源与上下文。** 切换来源时自动保存当前录制，尽量从历史缓冲补回延迟日志，并标记剩余缺口。引导式上报会预览和导出本次采集的会话。(#198, #203)
- **同时发生的崩溃各自保留堆栈。** 短时间内的反复崩溃合并到一条持续更新的通知，过期的上下文文件会自动清理。(#194, closes #192)
- **处理无效筛选和大量复制。** 无效正则会显示错误，大量选中的日志可保存为会话，录制写入出错时会保留已落盘的内容。(#191, closes #190)

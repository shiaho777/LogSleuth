# Screenshot index

The English and Simplified Chinese project READMEs use this gallery.

Captured on November 26, 2026 using the viewer and SDK sample debug builds from commit `fd19e78` on a Pixel 7 emulator running Android 15 (API 35). The interface is in English. Portrait captures are 1080 × 2400 pixels, and the landscape capture is 2400 × 1080. The system status bar is in demo mode. The checkout examples use fictional test data, and the Sleuth Sample crash was triggered in the SDK demo.

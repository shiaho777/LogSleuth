# Screenshot index

The English and Simplified Chinese READMEs show these images in the same order, from first launch to the SDK import flow. Each screenshot opens at full size from its tile.

Captured on November 26, 2026 from the debug builds of commit `fd19e78` on a Pixel 7 emulator running Android 15 (API 35). The interface is in English. Portrait images are 1080 × 2400 pixels, and the landscape image is 2400 × 1080. The status bar is in demo mode. Checkout and SDK logs contain test data.

Files are under `viewer-fd19e78/`.

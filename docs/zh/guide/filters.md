# 过滤与规则

一台忙着的手机每分钟能产生上千行日志。LogSleuth 用三层来收窄，而且这三层
对列表、录制和复制动作是同一套条件——你看到的、录下来的、复制走的，始终一致。

## 级别

过滤栏的第一个胶囊是级别集合。点开可以逐个开关 `V`、`D`、`I`、`W`、`E`、
`F`、`A`，胶囊上会用最短的说法显示当前选择（`≥ Warn`、`V+D+I+W+F+A` 等）。

搜索是在这一层之上进行的：级别集合决定哪些行存在，查询决定其中哪些被高亮。

## 规则栈

过滤栏还会显示当前启用的规则。一条规则是一个保存下来的匹配条件——级别、tag、
查询、应用、精确 tag、排除、正则——多条可以同时生效。生效的规则以胶囊形式
出现在过滤栏上，点一下就能关掉。

当规则把所有行都挡掉时，空状态会直接提供「全部关掉」，省得你一个个去找胶囊。

## 应用过滤

**全部应用** 表示不过滤。选一个应用，流就只剩这个包的内容。只有 Shizuku 和
root 路径能解析 uid 对应的包名，因此也只有它们能显示应用名。

## 从一行日志生成过滤器

长按某一行打开详情面板，点 **创建过滤器**。LogSleuth 不会直接塞一条
tag+pid 规则进去，而是打开过滤器编辑器，并预填 tag、pid、tid、uid、应用、
级别和截断后的消息。把不需要的字段删掉，再保存成规则或预设。

编辑器也可以从过滤栏的 **过滤器** 进入，在那里可以选应用、勾选允许的级别
集合。匹配时空字段会被忽略，所以只设了应用的规则会匹配该应用的全部行。

## 搜索

顶栏的放大镜会把工具栏切换成搜索框：

- 查询在可见列上匹配，旁边有大小写敏感开关；
- 命中计数显示 `3/57`，上下箭头可以在命中之间跳转；
- 键盘回车跳到下一条命中。

搜索只是高亮，不会改变缓冲区里有什么，所以清空查询就全部回来了。

## 预设

预设是保存下来的过滤器，一点即可套用。预设列在 **过滤器预设** 页面，可以启用、
停用和编辑。启用的预设等价于一条规则，会参与规则栈。

## 录制保存了什么

录制遵循**当前生效的完整过滤条件**——级别集合、查询、tag、排除、正则和应用
——所以录下来的就是你正在看的那部分。从顶栏、快捷设置磁贴或悬浮控件都可以
开始录制。

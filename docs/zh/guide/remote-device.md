# 读取第二台设备（无线 ADB）

LogSleuth 可以通过无线 ADB 读取*另一台*安卓设备的日志——电视、备用手机、
平板都行。远程设备不需要安装 LogSleuth，也不需要 root：它自己的 `adbd`
会提供日志流，就像在电脑上执行 `adb logcat` 一样。

## 配置步骤

1. **在远程设备上**：用电脑连接设备，执行 `adb tcpip 5555` 启用传统
   TCP 监听，然后记下远程设备的 IP。
2. **在 LogSleuth 里**：设置 → 远程设备 → 填入主机和端口 → **测试连接**。
3. 远程设备屏幕可能弹出**"允许 USB 调试吗？"**——在那台设备上点允许
   （勾选"一律允许"下次就不再弹）。LogSleuth 用的是自己的密钥，保存在
   应用私有目录里。
4. 状态显示*已连接*后，在授权模式列表里选**远程设备（无线 ADB）**。此后
   日志流、过滤、录制和崩溃侦测就都作用在远程设备的日志上了。

## 你能得到什么

- 日志和 UID 对应的包名来自远程设备。一个 UID 对应多个包名时，日志会保留
  UID。实时流、会话和导出文件都会标明远程地址。
- 录制、崩溃与 ANR 侦测及自动化规则都支持远程日志。切换来源会结束并保存
  当前录制。远程断开后，如有本机权限，实时流会提示已切回本机。要恢复远程
  采集，在设置里重新测试连接。

## 使用限制

- 一次采集一台设备。
- 远程采集走传统 TCP ADB 监听。Android 的 TLS 配对端口与配对码流程仍待支持。
- 两台设备需要通过网络互相可达，连接直接在设备之间建立。

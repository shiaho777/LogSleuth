# 读取第二台设备（无线 ADB）

LogSleuth 可以通过无线 ADB 读取*另一台*安卓设备的日志——电视、备用手机、
平板都行。远程设备不需要安装 LogSleuth，也不需要 root：它自己的 `adbd`
会提供日志流，就像在电脑上执行 `adb logcat` 一样。

## 配置步骤

1. **在远程设备上**：打开开发者选项 → 无线调试（Android 11+），或者先用
   电脑连一次并执行 `adb tcpip 5555`。记下它显示的 IP 和端口。
2. **在 LogSleuth 里**：设置 → 远程设备 → 填入主机和端口 → **测试连接**。
3. 远程设备屏幕可能弹出**"允许 USB 调试吗？"**——在那台设备上点允许
   （勾选"一律允许"下次就不再弹）。LogSleuth 用的是自己的密钥，保存在
   应用私有目录里。
4. 状态显示*已连接*后，在授权模式列表里选**远程设备（无线 ADB）**。此后
   日志流、过滤、录制和崩溃侦测就都作用在远程设备的日志上了。

## 你能得到什么

- 完整缓冲集 + uid 列（远程 shell 以 uid 2000 运行），所以按应用过滤和
  Shizuku 路径一样可用。
- 录制、会话、崩溃/ANR 侦测、自动化规则对远程流同样生效。
- 连接断开时，LogSleuth 会回退到本地授权路径，而不是让流空掉；远程设备
  恢复后到设置里重连即可。

## 诚实的限制

- 一次只能连一台远程设备——引擎只持有一条 logcat 流。
- Android 11+ 的*配对码*流程（`adb pair`）尚未实现；请用传统的
  `adb tcpip` 端口，或先用电脑配对一次再连它的调试端口。只接受 TLS 配对
  连接的设备会被明确报错拒绝。
- 两台设备需在同一网络（或互相可达）；不经过任何服务器——连接是设备对
  设备的。
